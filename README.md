# CUDA and Kernels

These notes cover CUDA programming from the basic building blocks of CUDA C++ through GPU execution, memory, kernels, and performance work.

Each note combines an explanation with a small runnable CUDA program. The focus is on understanding what the host does, what the device does, and how the two sides work together.
